# v0.6 prototype

- Windows Phone-inspired thin clock font, rectangular battery and discrete cellular signal bars. Native positions and view ancestry are preserved.
- Native battery controllers still supply level, charging and unknown-state information. Carrier-change and no-internet signal attribution retain native rendering.
- Tile styling is reapplied after resource/configuration updates, including replacement background drawables on theme changes.
- Tile labels, icons, panel, brightness, editor and power-menu colors follow light/dark configuration.

On-device checks: APK build/signature verification, installation, root restored, module loads without hook exceptions, and dark → light → dark switching without SystemUI process restart. Exact visual matching remains subject to user review.

An earlier development build moved status icons out of their vendor-required container and caused SystemUI crashes. Recovery used the matching stock init_boot, installed a corrected APK, then restored KernelSU. This release does not move status-bar elements or install position listeners.
